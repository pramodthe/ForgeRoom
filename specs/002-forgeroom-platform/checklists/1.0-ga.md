# 1.0 GA release checklist

## Stable product contract

- [ ] All required P3 and earlier-release tasks are `done`.
- [ ] Public API/event/export/extension compatibility, deprecation and LTS policies are published and conformance-tested.
- [ ] Release notes truthfully distinguish core, hosted, enterprise, optional, experimental and excluded capabilities.
- [ ] Self-hosted users can export all user-owned data without hosted contact.

## Security, scale and recovery

- [ ] Independent security review has no unresolved critical/high finding.
- [ ] Supply-chain signing, SBOM, provenance, vulnerability and secret checks pass.
- [ ] Supported load, quota, noisy-neighbor and backpressure budgets pass.
- [ ] HA/failover and disaster restore meet published RPO/RTO without duplicate external effects.
- [ ] Upgrade/restore/export matrix passes for every supported release/topology.
- [ ] Tenant, region/key, retention/deletion and operator-access tests pass.
- [ ] Signed-extension tests pass; SSO/SCIM/custom-policy tests pass only when the optional enterprise package is included in the release.

## Release and governance

- [ ] Signed artifacts, checksums, migrations, fixtures and documentation are published.
- [ ] Vulnerability response, contributor governance and support boundaries are public.
- [ ] Product, engineering, security and OSS governance approve P3-503 evidence.
