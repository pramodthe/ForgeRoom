# 0.2 private-alpha release checklist

Do not check an item until linked task evidence exists.

## Product and safety

- [ ] All required P1 tasks are `done`; optional/experimental tasks are clearly excluded or separately conformant.
- [ ] P0 regression, approval/action reconciliation and controlled GenUI gates still pass.
- [ ] Two humans collaborate in a private channel with immediate access revocation.
- [ ] Files/URLs/repositories ingest safely and consequential answers cite exact current sources or say no source.
- [ ] Memory is sourced, scoped, reviewable, editable, expirable and deletable.
- [ ] Global search/Run history passes private-scope, field, count/snippet, revocation, deletion and rebuild tests.
- [ ] Typed records remain authoritative and enforce schema/row/field/revision policy.
- [ ] Skills support tests, versions, bindings, rollback and safe import/export.
- [ ] Multiple workspace service connections remain exact-account/tool pinned; OAuth, drift, revoke and two-account isolation tests pass.
- [ ] Workspace event sequence, audit checkpoints/export and tamper detection pass without storing forbidden content.
- [ ] `standard-1` retention, classification, legal-hold, deletion propagation and same-release portable snapshot/import pass across every shipped domain.
- [ ] A populated 0.1 fixture upgrades without changing stable identities, revisions, permissions, pending actions or replay results.
- [ ] Spec-graph CI passes ID/link/release-order/index/dependency/gate checks.
- [ ] Cross-domain isolation, injection, revocation and deletion matrices pass.

## Operations and open source

- [ ] Clean documented single-node install reaches first trusted result.
- [ ] Backup/restore and full export/import pass from released artifacts.
- [ ] Previous release upgrade/forward-fix procedure passes.
- [ ] Telemetry is network-silent by default and diagnostics are redacted.
- [ ] License/NOTICE/SBOM/dependency and vulnerability checks pass.
- [ ] Contributor, conduct, security, architecture, setup, testing, migration, release, support and governance docs pass clean-clone link/command checks.
- [ ] Private security reporting, acknowledgement target, supported-version/coordinated-disclosure policy and signed-advisory verification are published and table-tested.

## Trial gate

- [ ] Five design-partner workspaces complete the two-week trial.
- [ ] No unresolved critical data-loss or authorization defect remains.
- [ ] Trial/product metrics exclude private content and known issues have owners.
- [ ] P1-504 contains release provenance, reports and gate approval.
