# P1-502 — Complete alpha browser E2E

## Outcome

One repeatable browser suite proves a real small-team journey from invite and knowledge ingestion through cited work, memory review, records and reusable skills.

## Acceptance criteria

- [ ] Owner invites a member, creates a private channel and verifies a non-member cannot enumerate or stream it.
- [ ] Member uploads a supported document and URL/repository source, observes processing and receives exact citations.
- [ ] A coworker proposes memory; an authorized human reviews it, then edits/expires it with visible history.
- [ ] Work creates/updates a typed record and controlled view with provenance.
- [ ] A private skill is tested, versioned, attached and invoked under unchanged approval boundaries.
- [ ] Refresh/reconnect and membership removal preserve truth and authorization at each phase.
- [ ] Tests use accessible locators/event waits and traces pass the sensitive-data scan.

## Verification

Run the suite three times after environment reset in Chromium plus the supported accessibility/browser matrix.
